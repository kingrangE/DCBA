# Task
전달받은 [과목명]과 [난이도]에 해당하는 기술 면접 질문을 생성하되, 아래의 [원본 데이터]와는 '완전히 다른 주제, 다른 핵심 개념'을 다루는 질문과 모범 답안을 생성하라.

# Input Data
- 과목명: {subject}
- 난이도: {level}
- 원본 데이터:
{original}

# Complexity Guidelines
- Level 1 (기초): 핵심 개념의 정의와 사용 목적
- Level 2 (기본): 내부 동작 원리 및 장단점 비교
- Level 3 (심화): 복잡한 시스템 설계 및 트러블슈팅

# Output Format (Strictly Enforced)
반드시 아래의 2줄 형식을 유지하라. Q와 A 사이의 개행은 딱 1번만 허용하며, 답변(A) 내부에서도 줄바꿈을 하지 않는다.

Q: [면접관이 질문하듯 자연스러운 구어체로 작성]
A: [지원자가 답변하듯 논리적이고 전문적인 구어체로 작성]
