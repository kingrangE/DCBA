# PostgreSQL 최신순 탐색 검증

이 문서는 계정 collation 변경 전의 검색 최적화 실험이다. 배포 코드의 이관·로그인·역이관 검증은 [전환 기록](postgresql-cutover.md)에 있다.
문항 50,000건, 저장 5,000건, 차단 500건의 합성 데이터에서 읽기 95%·쓰기 5%로 시험했다. 각 반복은 초기 분포를 복구한 뒤 3초 워밍업과 8초 측정을 거쳤다. 표의 지연은 반복 중앙값(ms), 오류율은 반복별 최솟값과 최댓값이다.

## 초당 75건 쓰기와 리소스

| 엔진 | 저장·취소 p95 | 차단·해제 p95 | SQL 추가 p95 | 관리자 삭제 p95 | DB CPU 초 | 블록 읽기 / 쓰기 | 평균 연결 획득 ms |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| MariaDB | 34.98 | 50.59 | 6.62 | 14.27 | 5.06 | 0 B / 94,720 B | 0.687 |
| PostgreSQL 최신순 탐색 | 11.44 | 16.48 | 7.70 | 20.59 | 0.85 | 0 B / 294,912 B | 0.002 |

쓰기 p95는 성공 응답을 집계했다. 각 유형의 표본은 적으며 운영 트래픽은 이번 시험 범위 밖이다. SQL 추가는 별도의 모델 호출이나 생성 이력 쓰기 없이 문항 행만 썼다.
